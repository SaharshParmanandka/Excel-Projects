# Ferns and Petals Sales Analysis

## Project Overview
This project analyzes the sales data of Ferns and Petals, providing insights into revenue, customer behavior, and popular trends using interactive dashboards created in Excel.

## Key Features
- **Total Revenue**: ₹3,520,984
- **Total Orders Placed**: 1,000
- **Average Delivery Time**: 5.53 hours
- **Average Customer Spending**: ₹3,520.98

## Dashboards Included
1. **Sales by Month**: Visualizes revenue trends over months.
2. **Top Popular Items**: Highlights bestselling categories (e.g., Cakes, Colors, Soft Toys).
3. **Top Cities**: Identifies cities with the highest order volumes.
4. **Order Days**: Shows the most active days of the week for sales.
5. **Top Sales by Hour**: Displays peak sales hours.
6. **Occasion Analysis**: Revenue breakdown by occasions such as Raksha Bandhan, Diwali, etc.

## Tools and Skills Used
- **Microsoft Excel**: Data visualization using Pivot Tables and Charts.
- **Data Cleaning**: Ensured consistent and accurate datasets.
- **Dashboard Creation**: Designed an interactive and user-friendly interface.

## Key Insights
- August and March are the months with the highest sales.
- Cakes are the most popular product category.
- Peak sales hours are between 12 PM and 8 PM.
- Wednesdays see the most orders among weekdays.

## How to Use
1. Download the project files from this repository.
2. Open the `Fnp Data Analysis.xlsx` file in Microsoft Excel.
3. Interact with slicers and filters to explore different views of the data.
